## Apple

[Canonical record](<../data/recognition/apple-web-security-recognition.json>)

**Recognition:** Apple publishes web-server security credits after reported issues have been identified and addressed\. [Apple web server security acknowledgements](<https://support.apple.com/en-us/102774>)

**Reporting:** Apple directs vulnerability reports to its own Apple Security Research portal, using an Apple Account\. [Report a security or privacy vulnerability](<https://support.apple.com/en-us/102549>) · [Apple Security Bounty Guidelines](<https://security.apple.com/bounty/guidelines/>)

**Rewards:** Apple Security Bounty has separate eligibility rules\. Appearance on the acknowledgment page does not establish a paid award\. [Apple Security Bounty Guidelines](<https://security.apple.com/bounty/guidelines/>)

**Limits:**
- The acknowledgment page concerns web-server reports; it is not a complete list of Apple security credits\.
- The authenticated submission flow was not opened or tested\.

## Motorola Solutions

[Canonical record](<../data/recognition/motorola-solutions-security-recognition.json>)

**Reporting:** The guidelines provide direct security-team email reporting for independent researchers\. [Responsible Vulnerability Disclosure Program Guidelines](<https://www.motorolasolutions.com/en_us/about/security-vulnerability/guidelines.html>)

**Rewards:** Recognition is discretionary; the guidelines disclaim any obligation to pay a bounty\. [Responsible Vulnerability Disclosure Program Guidelines](<https://www.motorolasolutions.com/en_us/about/security-vulnerability/guidelines.html>)

**Limits:**
- Customers and employees use separate reporting channels\.
- Recognition requires the first valid report and policy compliance; automated scanning is prohibited\.
