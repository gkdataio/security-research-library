# CTF and controlled practice

[All practice resources](resource-topics.md#topic-ctf-and-practice) · [Training-lab format](resource-types.md#type-training-lab) · [Learning guide](learning-guide.md) · [Library home](../README.md)

Use this lane to connect a security concept to an exercise in a provider-designated or isolated learning environment. CTF and practice are educational topics, not vulnerability families or evidence of a monetary award. Competition-award disclosure reports remain a separate collection.

## Choose a starting point

- [CyLab Security Academy](resources/cylab-security-academy-ctf-practice.md): the current Carnegie Mellon learning platform associated with picoCTF. Start with its introductory material and choose a manageable learning goal. The record explains the 2026 platform transition without treating that announcement as the curriculum's publication date.
- [OverTheWire Bandit](resources/overthewire-bandit-unix-foundations.md): command-line and Unix foundations for learners who need to understand files, permissions and basic system concepts before application-security material.
- [OverTheWire Natas](resources/overthewire-natas-web-security-practice.md): web-security practice for learners already comfortable with a browser and basic HTTP concepts.
- [PortSwigger Web Security Academy](resources/portswigger-web-security-academy-controlled-training.md): structured web learning across identity, access control, APIs, browser boundaries and application state.
- [OWASP Juice Shop](resources/owasp-juice-shop-controlled-training.md): a deliberately insecure application for connecting modern application design to security lessons in an isolated training setting.
- [OWASP WebGoat](resources/owasp-webgoat-controlled-training.md): guided lessons using a deliberately insecure application, with an emphasis on explaining the lesson and its mitigation.

These choices serve different prerequisites and learning styles. Access costs, software requirements and source-review limits are recorded on each page; a catalog entry does not establish that a particular hosted exercise or account is currently available. No exercise was run to prepare this collection.

## A useful learning record

Before an exercise, write down the environment the provider designates, the concept you want to understand and the limits of your activity. Afterwards, explain the intended security rule, why the example violates it, and which defensive design or validation principle addresses it. Keep observations separate from assumptions, and record where the learning environment simplifies real applications.

Do not extend exercise instructions to unrelated systems. Deliberately insecure applications require isolation; follow the provider's current setup, safety and usage guidance. This library provides high-level learning references, not payloads, challenge solutions or operational testing instructions.

Continue with [API security](resource-topics.md#topic-api-security), [browser security](resource-topics.md#topic-browser-security), [server/client frameworks](resource-topics.md#topic-server-client-frameworks), or the [research methodology](research-methodology.md) when the foundational concepts are clear.
